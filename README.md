# Volume Color

Volume Color is a custom indicator for MT4, MT5, and cTrader by EarnForex.com.

Volume Color displays the tick (or real) volume as colored bars directly in the main chart window of your trading platform.

Unlike the standard MetaTrader indicator, it colors the volume histogram according to the bullish/bearish nature of the corresponding price chart bars.

![Volume Color - an example of the daily EUR/USD chart with colored volume bars](https://github.com/EarnForex/Volume-Color/blob/main/volume-color-bars-daily-eurusd.png)
